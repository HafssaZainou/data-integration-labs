## What we hand to an agent, and what never

We hand steps to an agent where the result can be checked quickly and the step is small: a first draft of a download or cleaning script after we agreed  
on a plan, or an explanation of what a line of code does. We never hand over the raw data, the tests, or the decision what counts as a correct result.  
In Task 6 an agent found only 3 of our 6 bugs and showed no numbers, so we checked every claim ourselves against the data. Whatever an agent writes goes  
into the team repo only after a human has read it and run the tests.
